# Modifier le site O’Tennis

## Se connecter

Ouvrir `https://restaurant-buvette-otennis.ch/wp-admin/` après la mise en ligne et utiliser votre compte WordPress personnel.

Le tableau de bord propose deux raccourcis : **Accueil, horaires et contact** et **Carte, plats et prix**.

## Modifier du texte, un prix ou les horaires

1. Ouvrir **Pages → Accueil** ou **Pages → Menu**.
2. Cliquer directement sur le texte ou le prix et le modifier. Les horaires se trouvent dans un tableau sur la page Accueil : cliquer dans la cellule concernée.
3. Cliquer sur **Prévisualiser** pour vérifier le résultat, puis sur **Enregistrer / Mettre à jour** pour publier.

## Remplacer ou ajouter une photo

Cliquer sur une image puis **Remplacer → Téléverser**, ou choisir une photo dans la médiathèque. Renseigner un texte alternatif décrivant la photo.

Pour ajouter une image à un plat, ouvrir la **Vue en liste** (icône avec trois lignes en haut à gauche), sélectionner le groupe du plat, puis ajouter un bloc **Image** à l’intérieur. Le nom, le prix et la description restent des blocs de texte.

## Ajouter ou supprimer un plat

Dans **Pages → Menu**, ouvrir la **Vue en liste**. Sélectionner le groupe contenant tout le plat, ouvrir son menu **⋮**, puis **Dupliquer**. Modifier le nom, le prix, la description et éventuellement la photo. Le groupe doit rester dans la catégorie correspondante.

Pour les boissons affichées en liste, sélectionner une ligne dans le bloc Liste puis ajouter ou supprimer un élément de liste.

Pour supprimer un plat entier, sélectionner son groupe dans la Vue en liste et choisir **Supprimer**. Vérifier l’aperçu avant d’enregistrer.

## Modifier les coordonnées ou la carte

Les coordonnées se trouvent dans **Pages → Accueil**. Si le numéro change, modifier aussi le lien du téléphone pour qu’il commence par `tel:` et le numéro international, par exemple `tel:+41324814831`. Pour l’email, modifier le texte et le lien `mailto:`.

Pour déplacer la carte, sélectionner le bloc **Carte du restaurant**, saisir la nouvelle adresse puis enregistrer. Le lien de vérification permet de contrôler l’emplacement dans Google Maps.

Les coordonnées du pied de page sont séparées : demander à l’administrateur de les mettre à jour dans **Apparence → Éditeur → Compositions / Éléments de modèle → Pied de page**.

## Retrouver une ancienne version

Dans les réglages de la page, ouvrir **Révisions** et sélectionner une version précédente. Pour une erreur avant l’enregistrement, utiliser **Annuler** dans l’éditeur.

Votre compte Éditeur permet de gérer le contenu des pages. L’administrateur s’occupe du thème, des accès et de l’hébergement.
